# 怎么跑这两个测试

这两个脚本会在无头 Chrome 里把页面真的跑起来，用代码去点按钮、填表单，
然后检查结果对不对，最后把 36 项 / 34 项的结果写进网页标题里。

## 为什么要用一个"复制出来加了一行"的临时文件

脚本得挂在页面里才能执行，所以做法是：把 `index.html` 复制到 `/tmp`，
在 `</body>` 前插一行 `<script src="...">`，再让 Chrome 打开这个副本。
原始文件一个字都不用改。

## 步骤

```sh
# 1. 复制一份到 /tmp
cp "/Users/gebilaozhang/Documents/Codex/我的项目/倒数日/index.html" /tmp/t.html

# 2. 把测试脚本挂进去（首页测试为例）
/usr/bin/sed -i '' 's|</body>|<script src="/Users/gebilaozhang/Documents/Codex/我的项目/倒数日/测试/冒烟测试-首页.js"></script></body>|' /tmp/t.html

# 3. 用无头 Chrome 打开，把结果 dump 出来
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --disable-gpu --no-first-run --no-default-browser-check \
  --disable-background-networking --disable-component-update \
  --user-data-dir=/tmp/chrome-test --window-size=520,900 \
  --virtual-time-budget=16000 --dump-dom file:///tmp/t.html > /tmp/out.html

# 4. 看结果（Chrome 不会自己退出，所以实际跑的时候要放到后台、几秒后 kill 掉）
grep -o '<title>[^<]*</title>' /tmp/out.html | tr '|' '\n'
```

多页面测试把第 2 步的脚本换成 `冒烟测试-多页面.js` 即可。

## 注意

- **Chrome 在这台机器上不会自己退出**，必须用「后台启动 + sleep + kill」的方式跑，
  否则命令会一直挂着。示例如下：

  ```sh
  "/Applications/.../Google Chrome" ... --dump-dom file:///tmp/t.html > /tmp/out.html &
  p=$!
  sleep 15
  kill $p
  ```

- 每次换一个 `--user-data-dir`，否则连续开两个 Chrome 会抢配置目录，
  第二个实例会退回到干净的配置，测试结果就不准了。

- 加了 `--force-prefers-reduced-motion` 的话动画会关掉，数字直接显示终值，
  截图会比较好看；但测试交互流程时不要加，要让它真的跑动画。

- 多页面测试会自己把「已登录」标记清掉，从登录页开始走一遍，所以不用额外准备。
