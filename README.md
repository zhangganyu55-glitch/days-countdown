# 倒数日

一个记录重要日子的单文件网页应用。界面参考 Days Matter 和 DayCraft 的极简风格，
色调是淡粉。

**在线地址**：https://zhangganyu55-glitch.github.io/days-countdown/

![首页](预览/首页.png)

## 页面

一共十二个页面，靠地址栏的 `#/` 切换，底部有四个 Tab（倒数日 / 日历 / 更多 / 我的）。

| 页面 | 地址 | 说明 |
| --- | --- | --- |
| 登录页 | 打开就是 | 演示用，任意输入即可进，也可以点「跳过」 |
| 首页 | `#/home` | 记录列表，大数字倒计时 |
| 倒数本 | `#/books` | 按分类的封面卡片 + 分组列表 |
| 日历 | `#/calendar` | 月历，有记录的日子打点，点开看当天 |
| 历史上的今天 | `#/today` | 日期翻牌 + 当天节日/生日/大事 |
| 日期计算器 | `#/calc` | 算相差天数，或往后推 N 天 |
| 里程碑 | `#/milestone` | 所有日子排成一条时间轴 |
| 事件库 | `#/library` | 12 个预设模板，点一下加进列表 |
| 归档与隐藏 | `#/archive` | 被隐藏的记录，可以恢复 |
| 强提醒 | `#/remind` | 每条记录设提前几天提醒 |
| 相册 · 纸条 | `#/album` | 给记录配图标和一句备注 |
| 更多 / 我的 | `#/more` `#/me` | 功能入口、统计、深浅色、导入导出、退出登录 |

## 功能

- 记录事件名、日期、图标、分类、备注，自动显示「还有 X 天」或「已经 X 天」
- 分类筛选、置顶、隐藏、删除（带二次确认）
- 每年重复：生日纪念日过了自动算下一年，含 2 月 29 日在平年的处理
- 列表 / 网格两种视图，深色模式
- 数据保存在浏览器本地（localStorage），不上传服务器；支持导出 / 导入 JSON

## 交互

卡片逐条错开进场、数字从 0 滚动到目标值（等卡片落位后才开始滚）、进度线从 0 生长、
悬停时卡片抬起 + 图标放大 + 数字让位 + 按钮浮现（四个动作错开）、
点卡片先压一下再升起面板、删除时用一个「影子」把滑出动画播完而后面卡片同时补位、
切分类交叉淡入、页面切换淡出滑入。

动效只有三档时长（150 / 280 / 420 毫秒）+ 一条 iOS 面板曲线，全页共用同一套节奏。
开了系统「减弱动态效果」会自动关闭动画。

## 技术

单个 HTML 文件，CSS 和 JS 全部内联，**不依赖任何框架和外部文件**，断网可用。
动画只用 `transform` 和 `opacity`，配合 `cubic-bezier` 缓动，保证 60 帧。

## 使用

双击 `index.html` 即可打开。

想让手机看，双击 `启动手机预览.command`，手机连同一个 Wi-Fi 后访问终端里打印的地址。

## 改配色

全部颜色都在 CSS 顶部的 `:root` 里，改一处即可。常用几个：

- `--accent`：点缀色（按钮、选中态、分类小圆点）
- `--num`：右侧大数字的颜色
- `--card-grad`：卡片底色渐变

## 跑测试

`测试/` 里有两个冒烟测试脚本，用无头 Chrome 真的点一遍所有交互：

- `冒烟测试-首页.js`：36 项，覆盖新增、编辑、删除、置顶、分类、视图、深浅色、本地存储
- `冒烟测试-多页面.js`：34 项，覆盖登录、Tab 切换、返回键、事件库、强提醒、归档恢复、日历、计算器

用法见 `测试/怎么跑.md`。

## 已知情况

- **「历史上的今天」只收录了 4 天**（9-22、01-01、05-04、10-01），因为这功能不联网。
  其他日期打开会显示「这一天还没有收录」。想加日期，改 JS 里的 `TODAY_DATA`。
- 在手机上测试时，右侧数字的位置是唯一需要真机确认的地方。
- **推代码必须绕开本机代理**，否则 `gh` 会误报令牌无效：

  ```
  env -u HTTP_PROXY -u HTTPS_PROXY -u ALL_PROXY NO_PROXY='*' no_proxy='*' git push
  ```

## 说明

第一次打开会有 4 条样例数据，在「我的 → 清空所有数据」可以一键清掉。
页面打开过一次的浏览器会记住数据，想恢复样例：地址后面加 `?reset=1` 打开一次即可。
