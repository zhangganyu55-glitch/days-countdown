# 倒数日

一个记录重要日子的单文件网页应用，界面参考 Days Matter 和 DayCraft 的极简风格。

在线地址：https://zhangganyu55-glitch.github.io/days-countdown/

## 功能

- 记录事件名、日期、图标、分类，自动显示「还有 X 天」或「已经 X 天」
- 分类筛选（学习 / 生活 / 纪念日 / 工作），可置顶、可删除（带二次确认）
- 每年重复：生日、纪念日过了自动算到下一年，含 2 月 29 日在平年的处理
- 列表视图 / 网格视图切换，深色模式
- 数据保存在浏览器本地（localStorage），不上传服务器；支持导出 / 导入 JSON

## 交互

卡片逐条错开进场、悬停浮起并显示置顶/删除按钮、数字从 0 滚动到目标值、
置顶时卡片补间飞回顶部、删除时滑出、编辑面板从底部滑入且顶部有实时预览、
深浅色切换整页平滑过渡。开了系统「减弱动态效果」会自动关闭动画。

## 技术

单个 HTML 文件，CSS 和 JS 全部内联，**不依赖任何框架和外部文件**，断网可用。
动画只用 `transform` 和 `opacity`，配合 `cubic-bezier` 缓动，保证 60 帧。

## 使用

双击 `index.html` 即可打开。想放到手机上预览，双击 `启动手机预览.command`，
手机连同一个 Wi-Fi 后访问终端里打印出来的地址。

## 说明

第一次打开会有几条样例数据，在「设置 → 清空所有数据」可以一键清掉。
